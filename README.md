# 回响 · echo

念念不忘，必有回响。

本仓库仅用于分发 Windows 安装包与更新文件。

[下载安装包](https://github.com/ywlEcho/music_echo_public/releases/latest/download/echo-win32-x64-Setup.exe) · [查看版本说明](https://github.com/ywlEcho/music_echo_public/releases)

下载后运行安装包，通过开始菜单或桌面快捷方式启动。安装版会自动检查更新，下载完成后可选择重启安装；歌单与曲库保留。

从便携版切换时，请先从托盘退出旧版，再安装。应用数据保存在 %APPDATA%\echo；卸载或更新不主动删除该目录。

公开发布初期未配置 Windows 代码签名，安装时可能显示发布者未验证提示。请核对本仓库来源及发布附件中的 SHA256SUMS.txt。
