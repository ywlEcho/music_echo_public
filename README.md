## 下载与安装前的重要提示

> [!WARNING]
> **当前版本尚未进行 Windows 代码签名，下载和安装时可能出现安全提示。**
>
> 浏览器或 Windows SmartScreen 可能显示“不常下载”“未知发布者”“无法验证发布者”或“Windows 已保护你的电脑”等提示。这类提示与数字签名和应用信誉有关；**它不等于已经检测到病毒，也不能据此认定文件一定安全。**
>
> **如果安全软件明确报告病毒、木马或具体威胁名称，请暂停安装，并在本仓库 Issues 提供完整提示及检测名称，等待排查。不要关闭安全防护来绕过警报。**
>
> 请仅从本仓库的 Releases 下载，并对照发布附件 `SHA256SUMS.txt` 核对文件。**校验值只用于确认文件一致性，不能替代安全检测。**
>
> 后续会评估可信代码签名或微软商店分发；目前不承诺所有设备都能无提示安装。

下载后运行安装包，通过开始菜单或桌面快捷方式启动。安装版会自动检查更新，下载完成后可选择重启安装；歌单与曲库保留。

从便携版切换时，请先从托盘退出旧版，再安装。应用数据保存在 %APPDATA%\echo；卸载或更新不主动删除该目录。
